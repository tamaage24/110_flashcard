# フラッシュカード Webアプリ

2歳の子どものための教育用フラッシュカードアプリです。  
単語カード・数字カード・計算カード・二語文モードを備えています。

---

## 機能

- **単語カード**
  - `public/images` フォルダのサブフォルダに画像を追加すると、自動で反映
  - フォルダ名 / ファイル名 をカードに表示（例: ライオン/オス）

- **数字カード**
  - 赤い点をランダムまたは規則的に配置
  - 左上に数値を表示
  - 点同士は重ならないように配置

- **計算カード**
  - 1問ごとにタップして「数1 → 演算子 → 数2 → 答え」と順に表示
  - 四則演算（＋ − × ÷）とランダム選択モードあり
  - 上限は 100

- **二語文カード**
  - 枠のみ実装（将来拡張予定）
